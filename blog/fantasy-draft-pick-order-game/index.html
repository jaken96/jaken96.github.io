Fantasy Draft Pick Order Game

A host-led trivia game that turns fantasy football draft-order selection into part of draft night. Eight players race through Disney and NFL questions to claim their picks.

View the project on GitHub

Play the game

Choose a category, read the question, and reveal the answer when everyone has buzzed in.

Open full screen

The question history stays in this browser tab and no player data is sent anywhere.

How it works

A host reads one question at a time. The first player to buzz in with the correct answer earns one point. When someone reaches the round's target, they claim the next available draft position and leave the round.

  • Picks 1–3 require 3 points each.
  • Picks 4–6 require 2 points each.
  • Pick 7 requires 1 point.
  • The final remaining player receives pick 8.

Under the hood

The game is built with plain HTML, CSS, and JavaScript. It ships with 255 curated questions—100 Disney questions and 155 NFL questions—and avoids repeating a question until its category has been exhausted in the current tab.
